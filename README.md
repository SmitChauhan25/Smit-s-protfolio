# Smit Chauhan — Personal Portfolio

> Modern, high-performance personal developer portfolio built with React 19, TypeScript, Vite, Tailwind CSS, and Framer Motion.

---

## 🚀 About the Project

An interactive, responsive personal portfolio website designed to showcase projects, professional experience, full-stack engineering skills, and UI/UX design work.

### ✨ Key Features
- **Modern Tech Stack**: Built with React 19, TypeScript, and Vite for fast performance and clean code.
- **Dynamic Animations & Micro-Interactions**: Smooth entrance, text reveal, and transition animations powered by Framer Motion and GSAP.
- **Responsive & Sleek Design**: Modern dark theme aesthetics crafted with Tailwind CSS.
- **Detailed Experience & Projects Showcase**: Experience timeline with company details, technical stack badges, and live project demos.
- **Interactive Terminal & Creative Elements**: Clean navigation, active indicators, and quick contact actions.

---

## 🛠️ Built With

- **Frontend Framework**: React 19
- **Language**: TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, GSAP
- **Icons**: Lucide React

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/SmitChauhan25/Smit-s-protfolio.git
   cd Smit-s-protfolio/prisma-studio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser to view the portfolio.
